# Employee Attrition Prediction & Risk Scoring

## Project Overview

This project focuses on predicting employee attrition and identifying employees who may have a higher risk of leaving an organization.

The system uses HR-related factors such as job satisfaction, work-life balance, overtime, monthly income, years at company, job involvement, and other employee characteristics to analyze attrition patterns and generate risk scores.

## Objectives

- Predict employee attrition using machine learning.
- Analyze factors associated with employee turnover.
- Identify employees with higher attrition risk.
- Generate employee risk scores.
- Perform HR data analysis and visualization.
- Support data-driven employee retention analysis.

## Machine Learning Model

The project uses a Random Forest Classifier for employee attrition prediction.

The following techniques are included:

- Data Preprocessing
- Exploratory Data Analysis
- Random Forest Classification
- Classification Report
- Confusion Matrix
- Feature Importance
- Employee Risk Scoring

- Years at Company

## Project Workflow

1. Generate and prepare the HR dataset.
2. Perform data preprocessing.
3. Conduct exploratory data analysis.
4. Prepare features for machine learning.
5. Train the Random Forest model.
6. Evaluate model performance.
7. Analyze feature importance.
8. Calculate employee attrition risk scores.
9. Identify higher-risk employees.
10. Export the analysis results.
